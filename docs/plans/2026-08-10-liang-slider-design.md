# 「滑动变祖器」设计方案

## 项目目标

制作一个单页互动网页。用户拖动滑块时，同一名男性的外貌与气场从「牢梁」连续进化到「梁祖」。六个命名状态是主节点，相邻节点保留五个中间等级，合计 31 级。

页面只做一件事：让用户拖动并观察变化。人物、状态名称和滑杆始终处于视觉中心。

## 交互结构

- 滑杆范围为 `0—30`，步长为 `1`。
- 六个主节点分别位于 `0、6、12、18、24、30`。
- 主节点依次为「牢梁」「小梁」「梁子」「梁圣」「梁神」「梁祖」。
- 每两个主节点之间存在五个可停留的中间等级。
- 鼠标拖动、触屏拖动、点击轨道和键盘方向键均可控制。
- 拖动过程中，人物图像、背景色、光效和状态文字同步变化。
- 状态名称按所在区间更新，在越过节点时做短促的字形反馈。

## 人物进化路线

所有主形态保持同一身份、正脸机位、相同画幅和相近光线，避免滑动时出现明显跳位。

### 牢梁

瘦削、肩背微缩，脸部肌肉缺乏支撑感。佩戴普通细框眼镜，目光略向上试探，眉毛轻抬，嘴角紧张收住。神情要带有讨好、畏缩和卑微感，像在等别人发话。

### 小梁

头部稍微抬起，眼神更集中，肩背打开一点，下颌轮廓开始出现。眉间轻皱，嘴角略向下，保留一点压着火气的不愉快感。整体仍是普通人。

### 梁子

以第二张参考图为主要依据。正脸、眼镜、清醒直接的目光，脸部比例自然。自信开始出现，仍能看出早期状态的身份特征。

### 梁圣

眉骨、颧骨和下颌同步增强，肩宽增加。眼镜可以变为更利落的深色细框，神态趋于稳定、冷静。衣领出现低调的朱红或黑金细节，为后续帝王形态预热。

### 梁神

以第三张参考图的锋利骨相为主要依据，保留同一人的眼睛、鼻形和发型线索。眉压眼、颧骨突出、下颌明显增宽，目光带压迫感。取消手势，保证所有形态都能正面对齐。

### 梁祖

进入彻底抽象状态。肩宽、眉骨和方形下颌继续夸张，仍保留可辨认的五官关系。身穿黑红帝服，佩戴中国古代皇帝式冕冠，前后垂有珠串冕旒。珠帘可以穿过脸部前景，但眼睛和主要身份特征必须可见。背景加入克制的帝王光轮与金色边缘光。

## 图像与过渡方案

先生成六张严格对齐的主形态照片。网页根据滑杆位置，在相邻主形态之间进行 Canvas 叠化、缩放和轻量几何位移。过渡分为 31 个可停留等级，渲染层保持连续插值。

主形态生成时使用统一约束：

- 1:1 正方形构图，头肩照，人物直视镜头。
- 头部中心、眼睛高度、肩线与裁切位置固定。
- 统一的柔和正面光，不使用复杂环境背景。
- 不生成文字、水印和额外人物。
- 从低阶到高阶逐渐增强骨相、肩宽、服装和光效。

## 视觉系统

整体是一台虚构的「梁系强度鉴定仪」。视觉基调从冷灰实验界面逐渐进入朱红与暗金。

- 背景：冷灰白 `#E8E9E5`，高阶逐渐混入墨黑 `#151515`。
- 正文：炭黑 `#171816`。
- 低阶辅助色：铅灰 `#777B76`。
- 强度色：朱砂红 `#B52B24`。
- 帝王强调色：旧金 `#C19A49`。
- 高光：骨白 `#F4F1E8`。

标题使用宋体或楷体类展示字，状态与正文使用苹方，刻度和等级使用等宽字体。页面不放说明卡片或功能菜单，保留足够留白。

最醒目的设计动作是「梁祖越界」：其帝冕与珠帘可以突破头像容器上沿。其他阶段收敛处理，让终点显得荒谬且有冲击力。

## 页面布局

```text
┌──────────────────────────────────────┐
│ 滑动变祖器                 梁系 00/30 │
│                                      │
│               巨大状态字             │
│            ┌────────────┐            │
│            │            │            │
│            │  正脸人物   │            │
│            │            │            │
│            └────────────┘            │
│                 牢梁                 │
│       ┃·····┃·····┃·····┃·····┃      │
│        拖动以增强梁系浓度             │

```

移动端维持同一层级，缩小头像和标题，将六个节点名称分成可读的短标签。不会新增第二套交互。

## 边界与失败处理

- 图片未加载完成时显示人物轮廓占位和加载进度，滑杆暂时锁定。
- 单张图片加载失败时退回最近可用主形态，界面提示刷新。
- 尊重系统的减少动态效果设置，关闭文字冲击与光效，仅保留必要叠化。
- 触摸滑动时阻止页面横向误滚动，不影响纵向浏览。

## 验收标准

- 六个主节点的文字与人物形态对应准确。
- 相邻节点之间存在五个明确可停留的等级。
- 拖动时头像不发生明显的中心跳位。
- 「牢梁」可读出卑微与畏缩，「小梁」可读出略微不愉快。
- 「梁神」达到夸张的强者骨相，「梁祖」具备冕旒帝冕和荒诞帝王气场。
- 桌面端、手机端和键盘操作均可完成全范围拖动。
- 页面首次加载后，拖动反馈稳定在浏览器动画帧内。
